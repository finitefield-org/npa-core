# Let-removal contract-freeze outcome

Milestone 1 froze the v0.4 wire, hash, source-diagnostic, sidecar, and fixture
contracts. Its temporary inventories, disposition ledgers, command transcript,
checksums, and helper were consumed during Milestones 2–6 and removed during
Milestone 7. The retained normative records are
[core-spec-v0.4.0](../core-spec-v0.4.0.md), the
[let-removal plan](../let-removal-plan.md), and the
[v0.9.0 release note](../release-notes-v0.9.0.md).

This directory is a non-executable outcome marker. It contains no old-host
commands, compatibility instructions, or raw migration evidence.
